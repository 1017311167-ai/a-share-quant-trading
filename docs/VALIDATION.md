# 策略稳健性与过拟合评估

## 1. 目标

策略研究不能只展示样本内最优收益或最高夏普。稳健性评估同时检查：

- 样本外表现。
- 连续滚动窗口。
- Walk-forward 逐窗重新选参。
- 参数邻域稳定性。
- 收益路径蒙特卡洛分布。
- 买入持有基准比较。
- 综合过拟合风险和稳健性分数。

## 2. 评估流程

```text
完整数据
  |
  +-> 样本内优化参数
  |      |
  |      +-> 样本外验证
  |      +-> 参数稳定性
  |
  +-> 固定参数滚动窗口
  |
  +-> Walk-forward：每折训练窗口优化，测试窗口验证
  |
  +-> 样本外收益块 bootstrap
  |
  +-> 买入持有基准比较
  |
  +-> 过拟合风险分级
```

## 4. 样本内/样本外

数据按时间顺序拆分：

- 样本内用于参数选择。
- 样本外只用于最终验证，不参与选参。
- 样本外指标下降越大，过拟合惩罚越高。

样本外数据不会打乱顺序，避免时间泄漏。

## 5. 滚动回测

固定一组参数，在多个连续测试窗口重复运行。

用途：

- 检查策略在不同市场阶段的稳定性。
- 观察收益、回撤和交易频率是否依赖单一时期。

滚动回测不会在每个窗口重新选参。

## 6. Walk-forward

每个 Walk-forward 折：

1. 使用训练窗口优化参数。
2. 冻结这组参数。
3. 在紧随其后的测试窗口运行。
4. 记录下个窗口的测试收益和基准收益。

支持两种训练窗口：

- `anchored`：训练窗口从数据起点开始逐渐扩大。
- `rolling`：训练窗口保持固定长度并向前滑动。

输出包含：

- 每折最优参数。
- 训练指标和测试指标。
- 测试收益。
- 同期买入持有收益。
- 正收益折数比例。
- 跑赢基准的折数比例。

## 7. 参数稳定性

参数稳定性不只检查第一名的收益，而是分析前 K 组参数：

- 前 K 组目标指标与最优值的中位数差距。
- 前 K 组参数在候选范围内的离散程度。
- 最优值附近是否形成连续、可解释的参数平台。

稳定性分数范围为 0 至 1。分数越高，表示最优参数越不依赖单点尖峰。

## 8. 蒙特卡洛

对样本外或 Walk-forward 拼接收益执行固定块 bootstrap。

输出：

- 正收益概率。
- 最大回撤超过 20% 的概率。
- 期末收益的 5%、25%、50%、75% 和 95% 分位数。
- 最大回撤分布分位数。

块 bootstrap 保留部分时间序列顺序，但无法覆盖历史数据中未出现的极端制度。

## 9. 基准比较

当前默认基准为同标的买入持有：

- 基准累计收益率。
- 基准波动率。
- 基准夏普比率。
- 基准最大回撤。
- 策略相对基准的超额收益。

策略未跑赢基准会产生过拟合风险惩罚。

## 10. 过拟合风险

风险等级：

- `LOW`：稳健性分数不低于 75。
- `MEDIUM`：稳健性分数在 50 至 75 之间。
- `HIGH`：稳健性分数低于 50。

评分同时考虑：

- 样本外指标衰减。
- Walk-forward 正收益折数和跑赢基准折数。
- 参数稳定性。
- 蒙特卡洛正收益概率。
- 样本外是否跑赢基准。
- 样本外交易样本数量。

评分不是收益预测，只用于识别研究可信度风险。

- 主要风险原因。

## 12. 解释原则

- 高风险策略不能仅因为样本内收益最高而进入实盘候选。
- 低风险不等于未来盈利，只表示历史数据结构下证据更一致。
- 样本外只有一次，不能替代持续模拟盘。
- Walk-forward 折数过少时，结论只能作为初步参考。
- 参数稳定性低通常意味着最优参数处于孤立的收益尖峰。

## 13. 当前边界

- 当前基准只有买入持有。
- 尚未支持多资产组合的 Walk-forward 基准。
- 蒙特卡洛基于历史收益重采样，不生成新的基本面或流动性制度。
- 过拟合评分规则需要在更多策略和数据上持续校准。
